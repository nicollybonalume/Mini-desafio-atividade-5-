# 🕹️ GameZone Retro

Projeto desenvolvido para a criação de uma página web informativa e promocional para uma loja fictícia de jogos e consoles retrô.

---

## 📑 Sobre o Projeto

O **GameZone Retro** é uma página web simples desenvolvida em HTML5, apresentando uma interface temática com cores vibrantes (roxo e amarelo) no estilo retrô. A página conta com navegação para links externos e internos, exibição de consoles disponíveis, tabela de preços de jogos clássicos e imagens ilustrativas.

---

## 💻 Tecnologias Utilizadas

- **HTML5**: Estruturação de conteúdo e marcação das tags.
- **CSS (Inline)**: Estilização visual direta nos elementos (cores de fundo, texto, alinhamento e tamanhos).

---

## 📌 Funcionalidades

- Lista de consoles clássicos suportados (NES, SNES, Sega Genesis, Atari 2600).
- Tabela com catálogo de jogos e seus respectivos preços.
- Links para acesso à loja externa e navegação interna por âncora.
- Layout responsivo básico com imagem da marca/logo.
